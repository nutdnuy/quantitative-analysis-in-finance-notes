# การวิเคราะห์เชิงปริมาณทางการเงิน

เว็บไซต์ Lecture note สำหรับหนังสือ *การวิเคราะห์เชิงปริมาณทางการเงิน* โดย ดร.วิชัย วิทยาเกียรติเลิศ

เนื้อหาในบทเรียนแสดงจากหน้า PDF ต้นฉบับโดยตรง เพื่อรักษาถ้อยคำ สมการ ตัวอย่าง ตาราง และภาพประกอบตามหนังสือครบถ้วน หน้าเว็บไซต์ทำหน้าที่เป็นสารบัญและตัวอ่านแยกบท ไม่มีหน้า Welcome แยกต่างหาก

## เปิดอ่าน

- สร้างเว็บไซต์ในเครื่อง: `python3 scripts/build_site.py`
- เริ่มเว็บในเครื่องด้วย `python3 -m http.server 8763 --directory site`
- ไฟล์ต้นฉบับอยู่ที่ `assets/QAF-completed-handbook.pdf`
- ชื่อบทและเลขหน้าสำหรับตัวอ่านแยกบทอยู่ใน `book.json`

เว็บไซต์ใช้หน้า PDF จริง โดยลิงก์บทจะเปิดไปยังหน้าแรกของบทในหนังสือฉบับเต็ม ตัวอ่าน PDF ของเบราว์เซอร์ยังให้ค้นหาและดาวน์โหลดต้นฉบับได้

## เผยแพร่

GitHub Actions สร้างหน้าเว็บแบบสถิตจากไฟล์ใน repository และเผยแพร่ผ่าน GitHub Pages เมื่อมีการ push ไปยัง `main` หรือสั่ง workflow ด้วยตนเอง

## สิทธิ์และที่มา

หนังสือและเนื้อหาต้นฉบับเป็นลิขสิทธิ์ของผู้เขียนตามที่ระบุใน PDF ต้นฉบับ ผู้เป็นเจ้าของโปรเจกต์แจ้งว่าได้รับอนุญาตจากผู้เขียนให้เผยแพร่เนื้อหาบนเว็บ โปรเจกต์นี้ไม่ให้สิทธิ์ใช้งานหนังสือต่อและไม่ได้กำหนดสัญญาอนุญาตใหม่ให้แก่เนื้อหาต้นฉบับ ดูรายละเอียดที่ `RIGHTS.md`.
