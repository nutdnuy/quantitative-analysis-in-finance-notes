## 3.3 วิธีอัตราส่วนคงที่

การประมาณอัตราดอกเบี้ยด้วยวิธีอัตราส่วนคงที่ (Constant Ratio Method :CRM) ค่าของอัตราดอกเบี้ยที่ประมาณได้ด้วยวิธีนี้ จะแทนด้วย สัญลักษณ์ $i^{crm}$

แนวความคิดของวิธีนี้ คือ จ่ายค่ารายงวดงวดละ $r$ บาท โดยแบ่งชำระดอกเบี้ยทุกๆงวดด้วยสัดส่วนที่เท่ากันทุกงวด นั่นคือ แบ่งจ่ายดอกเบี้ยงวดละ $\frac{C}{n}$ ดังนั้น ชำระเงินต้นในแต่ละงวดเป็นจำนวนเงิน $r-\frac{C}{n}$ ภายใต้เงื่อนไข $r>\frac{C}{n}$ โดยเงินที่ต้องชำระทั้งหมด เท่ากับ

$$nr=P_0+C\qquad(3.15)$$

และจะได้ค่ารายงวด

$$r=\frac{P_0+C}{n}\qquad(3.16)$$

เราสามารถแสดงการจ่ายชำระหนี้ ด้วยวิธีอัตราส่วนคงที่ ได้ดังในตารางต่อไปนี้

| งวดที่ | เงินที่ชำระ | ชำระเป็นค่าเงินต้น | ชำระเป็นค่าดอกเบี้ย | เงินต้นค้างชำระ $B_t$ |
|:---:|:---:|:---:|:---:|:---:|
| $0$ | | | | $P_0$ |
| $1$ | $r$ | $r-\frac{C}{n}$ | $\frac{C}{n}$ | $P_0-r+\frac{C}{n}$ |
| $2$ | $r$ | $r-\frac{C}{n}$ | $\frac{C}{n}$ | $P_0-2r+\frac{2C}{n}$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |
| $n-1$ | $r$ | $r-\frac{C}{n}$ | $\frac{C}{n}$ | $P_0-(n-1)r+\frac{(n-1)C}{n}$ |
| $n$ | $r$ | $r-\frac{C}{n}$ | $\frac{C}{n}$ | $0$ |
| รวม | $nr=P_0+C$ | $nr-C=P_0$ | $C$ | |

เนื่องจาก $i$ เป็นอัตราดอกเบี้ยเพียงในนาม คิดทบต้น $m$ ครั้งต่อปี ดังนั้น อัตราดอกเบี้ยต่องวดเท่ากับ $\frac{i}{m}$ และ ดอกเบี้ยจ่ายในปลายงวดที่ $t$ คือ

$$I_t=\frac{i}{m}B_{t-1}\qquad(3.17)$$

สำหรับทุกๆ $t=1,2,...,n$ โดยที่ $B_0=P_0$
